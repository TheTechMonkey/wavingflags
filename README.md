# Waving Flags

Flags that really wave in the wind, in any design you can make on a banner.

Fabric mod for Minecraft 26.3. Needs Fabric API. Install on the server and every client.

## How to use

1. Design a banner in the loom (any base color, any patterns: stripes, crosses, borders,
   checks, chevrons, gradients and so on).
2. Craft the banner with sticks, anywhere in the grid:
   - banner + 1 stick = **Small Flag** (1 fence post tall)
   - banner + 2 sticks = **Medium Flag** (2 fence posts tall)
   - banner + 3 sticks = **Large Flag** (3 fence posts tall)
3. Build a pole out of fences and right-click the side of the top post. The flag hangs off
   that side, top edge level with the post, and flies away from it.

Flags are 1.5 times as long as they are tall. The cloth is real rippling geometry, so it
looks right from every angle, and each flag waves a little out of step with its neighbors.
Break the flag (or its post) and you get it back with its design. Plain flags in every color
are in the Waving Flags creative tab.
